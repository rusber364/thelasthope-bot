// Пример файла опроса. Строки, начинающиеся с «//», — комментарии, бот их пропускает.
// Отредактируй под себя, сохрани в UTF-8 и загрузи командой /poll create.
//
//   # …              заголовок опроса (один на файл)
//   текст            описание под заголовком (можно в несколько абзацев)
//   Картинка: URL    баннер (или прикрепи картинку параметром image в /poll create)
//   Анонимный: да    офицеры увидят только статистику, без имён
//   Кнопка: …        текст кнопки на сообщении опроса
//   Время: 5         сколько минут занимает опрос (иначе бот посчитает сам)
//
//   ## …             блок = одна страница-форма (до 5 вопросов)
//   Если: Вопрос = Вариант     блок показывается только при таком ответе
//   Если: Вопрос != Вариант    …или только если такой вариант НЕ выбран
//
//   ### Вопрос *     «*» в конце — обязательный вопрос (до 45 символов)
//   пояснение        строка под вопросом (до 100 символов)
//   ( ) вариант      выбрать один (до 10 — кружочки, больше — выпадающий список)
//   [ ] вариант      выбрать несколько (до 10 — галочки, больше — выпадающий список)
//   ( ) вариант | подсказка     серая подсказка под вариантом
//   Ответ: короткий  ответ текстом в одну строку («длинный» — в несколько строк)
