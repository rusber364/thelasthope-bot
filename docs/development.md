# Для разработчиков

Как запустить бота, как он устроен и где что лежит. Руководство для участников и офицеров — в [guide.md](guide.md).

**Стек:** [Node.js](https://nodejs.org) 26+ (встроенные SQLite и Temporal, `.ts` запускается без сборки), TypeScript, [discord.js](https://discord.js.org) v14, [pnpm](https://pnpm.io).

## Запуск

Нужны Node.js 26 или новее и pnpm (`npm install -g pnpm`, если его ещё нет).

### 1. Приложение в Discord

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. На вкладке **General Information** скопируй **Application ID**. Это `CLIENT_ID`.
3. На вкладке **Bot**:
   - нажми **Reset Token**. Это `DISCORD_TOKEN`. **Никому его не показывай**, а если он утёк, сбрось ещё раз;
   - включи **Server Members Intent** (для приветствия) и **Message Content Intent** (для фильтра мата), затем **Save Changes**.

### 2. Настройка

```bash
pnpm install
```

Скопируй `.env.example` в `.env` и заполни его. Чтобы копировать ID, включи в Discord **Настройки → Расширенные → Режим разработчика**: тогда в меню по ПКМ появится «Копировать ID».

### 3. Команды и запуск

Сначала пригласи бота на сервер по ссылке (её выводит `pnpm dev` при запуске, а `pnpm deploy` — при ошибке «Missing Access»), затем:

```bash
pnpm deploy
```

```bash
pnpm dev
```

В **Настройках сервера → Роли** перетащи роль бота **выше** ролей «Гость» и тех, кого он должен модерировать.

При первом запуске бот сам загрузит 49 родных иконок WoW (классы, спеки, роли и шапка реги) с wowhead как свои эмодзи. В консоли это строка `🎨 Иконки WoW: 49/49`. Если какая-то не загрузилась, бот попробует снова при следующем запуске.

### 4. Проверка

- **Рега:** `/raid open-now` сразу создаст реги в обоих каналах, ждать полуночи не нужно. Чтобы проверить напоминание «за час», создай `/raid create` со временем через 1 час 3 минуты и запишись.
- **Приветствие:** зайди на сервер со второго аккаунта.
- **Опрос:** `/poll template`, затем `/poll create` с этим файлом.
- **Фильтр мата:** напиши что-нибудь нецензурное со второго аккаунта.

## Скрипты

| Команда | Что делает |
|---|---|
| `pnpm dev` | Запуск с автоперезапуском при изменении кода |
| `pnpm start` | Обычный запуск |
| `pnpm deploy` | Отправить список команд в Discord (после добавления или изменения команды). С `GUILD_ID` — только на этот сервер, глобальные команды при этом очищаются, чтобы не было дублей |
| `pnpm test` | Тесты: разбор опросов, расписание, фильтр мата |
| `pnpm typecheck` | Проверка типов TypeScript |

## Как это работает

### Бот — это программа, которая держит соединение с Discord

```
 Компьютер или сервер                       Discord
┌─────────────────┐   WebSocket (Gateway)   ┌──────────────┐
│  node index.ts  │ ◄────── события ─────── │              │
│  (discord.js)   │                         │   серверы,   │
│                 │ ──── HTTP-запросы ────► │   участники  │
└─────────────────┘ (ответить, кикнуть, …)  └──────────────┘
         │
         ▼
   data/bot.db  ← реги, записи, опросы, ответы (переживают перезапуск)
```

- `client.login(token)` открывает постоянное соединение (**Gateway**). Через него Discord **присылает события**: «зашёл участник», «новое сообщение», «нажата кнопка»…
- Чтобы **что-то сделать**, бот отправляет HTTP-запросы: `channel.send()`, `member.roles.add()` и т.п.
- Бот онлайн, пока программа запущена. Для работы 24/7 его запускают на сервере (VPS).

### Intents — на что бот подписан

В [src/index.ts](../src/index.ts) перечислены группы событий, которые бот хочет получать. Два из них привилегированные и включаются вручную в Developer Portal: **Server Members** (вход участников) и **Message Content** (текст сообщений для фильтра мата).

### Слэш-команды живут на стороне Discord

У каждой команды есть **описание** (`data`: имя, параметры, права) и **обработчик** (`execute`). Описание отправляется в Discord командой `pnpm deploy`, и Discord по нему показывает подсказки, когда пишешь `/`. Когда команду вызывают, приходит событие `interactionCreate`, и бот запускает нужный `execute`.

### Кнопки, меню и формы

У каждой кнопки, меню и формы есть `customId` — строка, которую Discord вернёт боту при нажатии. Бот кладёт туда всё, что нужно знать: `raid:spec:12` — «выбор спека в реге №12», `poll:submit:3:1` — «отправлен блок 1 опроса №3». [src/events/interactionCreate.ts](../src/events/interactionCreate.ts) смотрит на первую часть (`raid`, `poll`, `welcome`, `role`) и передаёт нажатие нужному модулю ([src/components.ts](../src/components.ts)). Поэтому кнопки продолжают работать и после перезапуска бота.

На каждое нажатие нужно ответить за **3 секунды**, иначе Discord покажет «Приложение не отвечает». Поэтому бот сначала отвечает человеку, а потом спокойно перерисовывает регу.

### Как выглядят сообщения

- **Рега** — embed в стиле Raid-Helper ([src/raids/render.ts](../src/raids/render.ts)). Колонки — это «поля» embed'а: Discord ставит по три поля в ряд, поэтому танки, ближний и дальний бой идут первым рядом, лекари — под танками. Баннер — отдельный embed сверху.
- **Приветствие и опросы** — Components V2: контейнер с цветной полоской, текст, картинка, кнопки внутри.

### Формы опросов

Одна страница опроса — это **модальное окно** (форма) Discord с вопросами блока, максимум 5. Бот сам выбирает элемент: до 10 вариантов — кружочки или галочки, больше — выпадающий список. Discord не позволяет открыть следующую форму сразу после предыдущей, поэтому между блоками показывается личная карточка с кнопкой «Продолжить».

### Расписание и напоминания

[src/raids/scheduler.ts](../src/raids/scheduler.ts) раз в 30 секунд проверяет базу и часы (по Киеву, с учётом перехода на летнее и зимнее время). Он открывает реги, рассылает напоминания и закрывает запись. Всё сделанное отмечается в базе, поэтому перезапуск ничего не задваивает. Если бот был выключен в полночь, рега откроется, как только он включится (в течение 6 часов).

## Структура проекта

```
src/
├── index.ts, config.ts, settings.ts, db.ts, components.ts
├── commands/        ← слэш-команды (general, moderation, roles, raids, polls)
├── events/          ← события: ready, interactionCreate, guildMemberAdd, profanityFilter
├── welcome/         ← приветствие и кнопка «Гость»
├── raids/           ← классы/спеки, иконки, вид реги, кнопки, планировщик, база
├── polls/           ← формат файла опроса, формы, итоги, база
└── lib/             ← общее: время, фильтр мата, журнал модерации, ссылка-приглашение
docs/                ← руководство (guide.md) и этот файл
examples/poll-example.txt  ← пример опроса
assets/                    ← баннер реги
```

## Как добавить свою команду

1. Скопируй [src/commands/general/ping.ts](../src/commands/general/ping.ts), например в `src/commands/general/roll.ts`, и поменяй имя, описание и `execute`.
2. Допиши её в список в [src/commands/index.ts](../src/commands/index.ts).
3. Выполни `pnpm deploy`; `pnpm dev` перезапустится сам.
