# Что готово и как проверить

Всё, что бот умеет сейчас, и проверка каждой функции в Discord по шагам. Отмечай пункты по мере проверки (`[ ]` → `[x]`). Подробно про каждую функцию — в [руководстве](guide.md).

## Коротко

| Что | Состояние |
| --- | --- |
| Каркас, команды и модерация, приветствие, реги, опросы, фильтр мата, логи, админка | работало и раньше; настройки переехали в админку — стоит быстро перепроверить (раздел 3) |
| Аватар и баннер бота | уже применены (`pnpm brand`) |
| Лог-рейдов, временная роль рейда, архив рег, прощания, голосовые роли, липкие сообщения | **новое**, в Discord ещё не запускалось (раздел 2) |
| Оповещения офицерам, посещаемость, «Сбор!», пинг роли, кто кого пригласил | **новое**, в Discord ещё не запускалось (раздел 2) |

Автотесты: 120, все проходят (`pnpm test`). Они проверяют логику на подставных объектах, но не заменяют проверку на живом сервере.

---

## 1. Подготовка (один раз)

- [ ] `pnpm install` — подтянуть новые пакеты.
- [ ] В `.env` заполнены `DISCORD_CLIENT_SECRET` и `SESSION_SECRET` (подсказки — в `.env.example`), а в Developer Portal → OAuth2 → Redirects добавлен `http://localhost:3000/auth/callback`.
- [ ] У роли бота есть права «Просматривать журнал аудита», «Управлять сервером» и «Управлять ролями». Проще всего переприглашить бота по ссылке, которую он печатает в консоли при запуске (`🔗 Пригласить бота на сервер`).
- [ ] Роль бота стоит **выше** ролей, которые он выдаёт: «Гость», временная роль рейда, голосовые роли.
- [ ] `pnpm deploy` — у `/raid create` появился параметр `ping`.
- [ ] `pnpm dev` — бот запущен, админка открывается на http://localhost:3000.
- [ ] Под рукой второй аккаунт Discord: нужен, чтобы проверить вход, выход, приглашения и позднюю отписку.

## 2. Новое — проверить обязательно

### Аватар и баннер

- [ ] В профиле бота логотип гильдии на аватаре и на баннере. Если нет — главная админки → «Обновить аватар» / «Обновить баннер» (Discord может показывать старую картинку пару минут).

### Лог-рейдов

- [ ] Админка → «Логи»: выбрать канал для «лог-рейдов», поставить галочку, сохранить, нажать «Отправить тестовое сообщение в лог-каналы» → сообщение пришло.
- [ ] Записаться на регу, сменить спек, нажать «Под вопросом», отписаться → в «лог-рейдов» четыре записи: кто, на какую регу и что изменилось.

### Временная роль участникам рейда

- [ ] Создать роль, например «Рейд». Админка → «Расписание рег» → «Временная роль участникам» = «Рейд», «Снимать через» = 1 час.
- [ ] Записаться на регу → роль появилась. Отписаться → роль снята (если нет записи на другую открытую регу).
- [ ] Создать регу, которая скоро начнётся (`/raid create title:Тест time:<через 5 минут>`), записаться → через час после начала роль снимается сама.

### Архив прошедших рег

- [ ] «Расписание рег» → «Архив прошедших рег» = «Переносить в канал-архив», выбрать канал-архив, «через 1 час».
- [ ] Через час после начала тестовой реги: в канале-архиве итог и финальный состав, а сама рега из своего канала удалена.
- [ ] Режим «Удалять и оставлять краткий итог в канале реги» → рега удалена, на её месте короткий итог.

### Прощания

- [ ] Админка → «Приветствие» → «Прощание»: выбрать канал, сохранить, нажать «Прислать пробное прощание» → пришло с твоим ником и числом участников.
- [ ] Второй аккаунт выходит с сервера → прощание в выбранном канале.

### Голосовые роли

- [ ] Админка → «Каналы и роли» → голосовые роли: связка «голосовой канал → роль».
- [ ] Зайти в этот голосовой → роль выдана. Выйти или перейти в другой канал → роль снята.
- [ ] Перезапустить бота, пока кто-то сидит в канале → у сидящих роль есть, у тех, кто вышел, пока бот был выключен, — снята.

### Липкие сообщения

- [ ] Админка → «Липкие сообщения»: канал и текст, сохранить → текст сразу внизу канала с подписью «📌 закреплено».
- [ ] Написать в канал несколько сообщений подряд → через несколько секунд текст снова последний, старая копия удалена. Одна перестановка на пачку сообщений и не чаще, чем указано в настройке.
- [ ] Отметить «убрать из этого канала», сохранить → копия из канала удалена.

### Оповещения офицерам и посещаемость

- [ ] Админка → «Оповещения»: канал оповещений, роль офицеров, порог поздней отписки, «Сбор!», проверка посещаемости, голосовой канал рейда. Роль офицеров должна быть упоминаемой (настройки роли → «Разрешить всем @упоминать эту роль»).
- [ ] `/raid create title:Тест time:<через 30 минут> ping:@Рейдер` → в канале реги упоминание роли.
- [ ] Записаться с обоих аккаунтов. Вторым отписаться (рейд меньше чем через 3 часа) → в канале оповещений «поздняя отписка» с пингом офицеров.
- [ ] За 15 минут до начала — «Сбор!» в канале реги с упоминанием записавшихся.
- [ ] Через 15 минут после начала — отчёт о посещаемости в канале оповещений: кто в голосовом, кто не пришёл, кто «под вопросом», кто пришёл без записи.
- [ ] «Расписание рег» → у расписания выбрать «роль для пинга», затем `/raid open-now` → реги открылись с упоминанием роли.

### Кто кого пригласил

- [ ] Создать приглашение, зайти по нему вторым аккаунтом → в «лог-дискорда» в записи о входе видно, по чьему приглашению зашёл новичок.

## 3. Работало раньше — быстрая перепроверка

- [ ] `/ping` отвечает.
- [ ] Приветствие: в админке «Прислать пробное приветствие»; второй аккаунт заходит → приветствие, кнопка «Получить роль Гость» выдаёт роль.
- [ ] Реги: `/raid create` → колонки по ролям, иконки спеков, номера записей; запись (класс → спек), «Под вопросом», отписка; `/raid cancel`.
- [ ] Реги по расписанию: `/raid open-now` → открылись в каналах из «Расписания рег».
- [ ] Напоминания в личку: рега на завтра — за сутки, рега через час с небольшим — за час.
- [ ] Опросы: `/poll create file:…` с [примером](../examples/poll-example.txt) → «Пройти опрос», несколько страниц; `/poll results` — итоги и таблица; `/poll close`.
- [ ] Фильтр мата (со второго аккаунта) → сообщение удалено, одна запись в «лог-модерация», без дубля в «лог-сообщения».
- [ ] Модерация: `/mute`, `/unmute`, `/clear`, `/kick`, `/ban`, `/unban` → записи в «лог-модерация»; ручной тайм-аут через Discord тоже попадает туда, с тем, кто его дал.
- [ ] Логи: изменить и удалить сообщение → «лог-сообщения»; зайти в голосовой → «лог-голос»; переименовать канал или создать роль → «лог-сервер» с тем, кто это сделал.
- [ ] Админка: вход через Discord; аккаунт без права «Управлять сервером» видит «Нет доступа»; любое сохранение пишется в «лог-сервер».
