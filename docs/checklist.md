## 1. Подготовка (один раз)

- [x] `pnpm install` — подтянуть новые пакеты.
- [x] `pnpm build` — собрать новую админку (и после каждого обновления админки). Без этого на http://localhost:3000 будет «Админка не собрана».
- [x] В `.env` заполнены `DISCORD_CLIENT_SECRET` и `SESSION_SECRET` (подсказки — в `.env.example`), а в Developer Portal → OAuth2 → Redirects добавлен `http://localhost:3000/auth/callback`.
- [x] У роли бота есть права «Просматривать журнал аудита», «Управлять сервером» и «Управлять ролями». Проще всего переприглашить бота по ссылке, которую он печатает в консоли при запуске (`🔗 Пригласить бота на сервер`).
- [x] Роль бота стоит **выше** ролей, которые он выдаёт: «Гость», временная роль рейда, голосовые роли.
- [x] `pnpm deploy` — обновить команды: `/raid create` теперь ведёт в личку, появилась `/raid quick`.
- [x] `pnpm dev` — бот запущен, админка открывается на http://localhost:3000.
- [x] Под рукой второй аккаунт Discord: нужен, чтобы проверить вход, выход, приглашения и позднюю отписку.

### Сборы трёх видов, лимиты и группы игроков

- [ ] Админка → «Сборы»: у шаблона «Вид» = «Подземелье» → подставились 5 мест и 1 / 1 / 3. Лимиты в сумме больше мест → «Не сохранено» с понятной ошибкой.
- [ ] Рега подземелья: в начале «**Подземелье** · 5 мест · 1 танк, 1 лекарь, 3 бойца», колонки «Танки (0/1)», «Лекари (0/1)».
- [ ] Основной аккаунт — танк, второй — тоже танк: у второго сразу после кнопки «Танк» — «Танки уже набраны (1) — запишу в запас», после записи «Танки уже набраны (1/1)», он в запасе. Основной меняет спек на бойца — второй поднимается в основу.

- [ ] `/group limits … healers:2` вторым аккаунтом → рега перерисовалась, «Лекари (…/2)». `/group cancel` чужой группы — «Это не твоя группа»; офицером — отменилась, записавшимся пришло «… отменили».

### Напоминание тем, кто записался поздно

- [ ] Шаблон с регой, которая открывается за 30 минут до рейда → записаться после открытия → бот отвечает «Напомню … за 15 минут до начала» → за 15 минут до начала в личку приходит «Напоминание: рейд … начнётся …», одно.
- [ ] Записаться меньше чем за 15 минут до начала → бот отвечает, что напоминания в личку уже не будет, и его действительно нет.
