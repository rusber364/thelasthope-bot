# Что готово и как проверить

Всё, что бот умеет сейчас, и проверка каждой функции в Discord по шагам. Отмечай пункты по мере проверки (`[ ]` → `[x]`). Подробно про каждую функцию — в [руководстве](guide.md).

## Коротко

| Что | Состояние |
| --- | --- |
| Каркас, команды и модерация, приветствие, реги, опросы, фильтр мата, логи, админка | работало и раньше; настройки переехали в админку — стоит быстро перепроверить (раздел 3) |
| Аватар и баннер бота | уже применены (`pnpm brand`) |
| Шаблоны рег, личные напоминания, события Discord для рег и `/raid move`, список ближайших рейдов, лог-рейдов, временная роль рейда, архив рег, прощания, голосовые роли, липкие сообщения | **новое**, в Discord ещё не запускалось (раздел 2) |
| Приветствие в личку, опросы в админке, создание реги в личке | проверено в Discord |
| Оповещения офицерам, посещаемость, «Сбор!», пинг роли, кто кого пригласил | **новое**, в Discord ещё не запускалось (раздел 2) |

Автотесты: 120, все проходят (`pnpm test`). Они проверяют логику на подставных объектах, но не заменяют проверку на живом сервере.

---

## 1. Подготовка (один раз)

- [ ] `pnpm install` — подтянуть новые пакеты.
- [ ] В `.env` заполнены `DISCORD_CLIENT_SECRET` и `SESSION_SECRET` (подсказки — в `.env.example`), а в Developer Portal → OAuth2 → Redirects добавлен `http://localhost:3000/auth/callback`.
- [ ] У роли бота есть права «Просматривать журнал аудита», «Управлять сервером» и «Управлять ролями». Проще всего переприглашить бота по ссылке, которую он печатает в консоли при запуске (`🔗 Пригласить бота на сервер`).
- [ ] Роль бота стоит **выше** ролей, которые он выдаёт: «Гость», временная роль рейда, голосовые роли.
- [ ] `pnpm deploy` — обновить команды: `/raid create` теперь ведёт в личку, появилась `/raid quick`.
- [ ] `pnpm dev` — бот запущен, админка открывается на http://localhost:3000.
- [ ] Под рукой второй аккаунт Discord: нужен, чтобы проверить вход, выход, приглашения и позднюю отписку.

## 2. Новое — проверить обязательно

### Аватар и баннер

- [ ] В профиле бота логотип гильдии на аватаре и на баннере. Если нет — главная админки → «Обновить аватар» / «Обновить баннер» (Discord может показывать старую картинку пару минут).

### Лог-рейдов

- [ ] Админка → «Логи»: выбрать канал для «лог-рейдов», поставить галочку, сохранить, нажать «Отправить тестовое сообщение в лог-каналы» → сообщение пришло.
- [ ] Записаться на регу, сменить спек, нажать «Под вопросом», отписаться → в «лог-рейдов» четыре записи: кто, на какую регу и что изменилось.

### Временная роль участникам рейда

- [ ] Создать роль, например «Рейд». Админка → «Расписание рег» → «Временная роль участникам» = «Рейд», «Снимать через» = 1 час.
- [ ] Записаться на регу → роль появилась. Отписаться → роль снята (если нет записи на другую открытую регу).
- [ ] Создать регу, которая скоро начнётся (`/raid quick title:Тест time:<через 5 минут>`), записаться → через час после начала роль снимается сама.

### Архив прошедших рег

- [ ] «Расписание рег» → «Архив прошедших рег» = «Переносить в канал-архив», выбрать канал-архив, «через 1 час».
- [ ] Через час после начала тестовой реги: в канале-архиве итог и финальный состав, а сама рега из своего канала удалена.
- [ ] Режим «Удалять и оставлять краткий итог в канале реги» → рега удалена, на её месте короткий итог.

### Приветствие в личку

- [ ] Админка → «Приветствие» → «Приветствие в личку»: нажать «Прислать пробное тебе в личку» → в личке памятка с твоим ником и кнопки «Правила» и «Авторизация», которые открывают каналы.
- [ ] Поставить галочку «присылать новичкам в личку», сохранить. Второй аккаунт заходит на сервер → памятка в личке, приветствие в канале и роли — как обычно.
- [ ] Второму аккаунту закрыть личку (ПКМ по иконке сервера → Настройки конфиденциальности → выключить «Личные сообщения»), выйти и зайти снова → памятки нет, приветствие в канале есть, ошибок в консоли бота нет.

### Шаблоны рег

- [ ] Админка → «Шаблоны рег»: заполнить шаблон (название, описание, 20 мест, 19:30, канал, роль) → «Сохранить шаблоны».
- [ ] У шаблона выбрать завтрашнюю дату → «Создать регу» → рега в канале с описанием, размером, временем и пингом роли, автор — ты; в «лог-сервер» запись «Рега создана через админку».
- [ ] Изменить размер в шаблоне → следующая рега с новым размером. Удалить шаблон галочкой → пропал.

### Личные напоминания

- [ ] Под регой кнопка «Напомнить» → меню 10 мин / 30 мин / 1 ч / 2 ч (видно только тебе). Выбрать 10 минут на реге, которая начнётся через 15 минут → через 5 минут личка «Твоё напоминание».
- [ ] Выбрать время больше, чем осталось до рейда → бот просит выбрать поменьше.
- [ ] «Напомнить» → «Не напоминать» → напоминание не приходит.
- [ ] Поставить напоминание, перезапустить бота → напоминание всё равно приходит.

### События Discord для рег и перенос рейда

- [ ] Роли бота добавлено право «Создавать события» (Настройки сервера → Роли → The Last Hope Bot).
- [ ] Создать регу → во вкладке «События» сервера появилось событие с названием, временем, описанием и ссылкой на регу (и картинкой реги, если была).
- [ ] `/raid move` → время на реге и в событии изменилось, записавшимся пришло сообщение о переносе, напоминания придут от нового времени.
- [ ] `/raid cancel` → событие отменено (пропало из вкладки).
- [ ] После начала рейда событие отмечено идущим, через 3 часа само завершилось.
- [ ] Снять галочку «создавать события Discord» в админке → новые реги без событий.

### Список ближайших рейдов

- [ ] Админка → «Расписание рег» → «Живой список ближайших рейдов»: выбрать канал, сохранить → в канале сообщение «Ближайшие рейды».
- [ ] Создать регу → она появилась в списке (ближайшие сверху); записаться и нажать «Под вопросом» вторым аккаунтом → цифры обновились через пару секунд.
- [ ] Отменить регу (`/raid cancel`) → она пропала из списка; после начала рейда рега тоже уходит из списка.
- [ ] Удалить сообщение списка руками и записаться на регу → список опубликован заново. Сменить канал в админке → старое сообщение удалено, новое — в новом канале.

### Создание реги по шагам в личке

- [ ] `/raid create` в канале рег → ответ «Продолжим в личке» со ссылкой; в личке шаг 1 из 5.
- [ ] Пройти шаги: название, описание (или «Без описания»), дата кнопкой, время текстом, картинка файлом. Неверная дата (`32.13`, вчера) → бот объясняет и спрашивает снова; «Назад» возвращает на шаг.
- [ ] Предпросмотр: рега со своей картинкой; «Изменить…» → Название → после ответа снова предпросмотр.
- [ ] «Опубликовать» → рега в канале с картинкой и пингом роли (если был `ping`); запись работает, картинка не пропадает после записи и отписки.
- [ ] Без картинки («Стандартный фон») → обычный фон.
- [ ] Нажать кнопку в старом сообщении мастера → «уже опубликована или отменена», ничего не ломается.
- [ ] Закрыть личку от участников сервера → `/raid create` подсказывает открыть личку или `/raid quick`.
- [ ] Начать регу, перезапустить бота, продолжить отвечать → черновик на месте.

### Опросы в админке

- [ ] Админка → «Опросы» → «Новый опрос»: открылся шаблон. Изменить пару строк, обновить страницу → изменения на месте (черновик).
- [ ] Сломать строку (например, убрать `##` перед страницей) → «Проверить» → ошибка с номером строки; клик по ней выделяет строку.
- [ ] Исправить → «Проверить» → предпросмотр со страницами, вопросами и условиями.
- [ ] Выбрать канал, роль и картинку → «Опубликовать» → опрос появился в Discord с картинкой и упоминанием; «Пройти опрос» работает.
- [ ] Ответить с двух аккаунтов (один — не до конца) → на странице опроса проценты, «завершили / не закончили», текстовые ответы с именами.
- [ ] «Скачать таблицу для Excel» → файл открывается в Excel по столбцам, без кракозябр.
- [ ] «Создать копию» → в редакторе тот же текст и канал.
- [ ] «Закрыть опрос» → кнопка под опросом в Discord стала «Опрос закрыт»; в «лог-сервер» записи о публикации и закрытии.
- [ ] `/poll create`, `/poll results`, `/poll close` работают как раньше.

### Прощания

- [ ] Админка → «Приветствие» → «Прощание»: выбрать канал, сохранить, нажать «Прислать пробное прощание» → пришло с твоим ником и числом участников.
- [ ] Второй аккаунт выходит с сервера → прощание в выбранном канале.

### Голосовые роли

- [ ] Админка → «Каналы и роли» → голосовые роли: связка «голосовой канал → роль».
- [ ] Зайти в этот голосовой → роль выдана. Выйти или перейти в другой канал → роль снята.
- [ ] Перезапустить бота, пока кто-то сидит в канале → у сидящих роль есть, у тех, кто вышел, пока бот был выключен, — снята.

### Липкие сообщения

- [ ] Админка → «Липкие сообщения»: канал и текст, сохранить → текст сразу внизу канала с подписью «📌 закреплено».
- [ ] Написать в канал несколько сообщений подряд → через несколько секунд текст снова последний, старая копия удалена. Одна перестановка на пачку сообщений и не чаще, чем указано в настройке.
- [ ] Отметить «убрать из этого канала», сохранить → копия из канала удалена.

### Оповещения офицерам и посещаемость

- [ ] Админка → «Оповещения»: канал оповещений, роль офицеров, порог поздней отписки, «Сбор!», проверка посещаемости, голосовой канал рейда. Роль офицеров должна быть упоминаемой (настройки роли → «Разрешить всем @упоминать эту роль»).
- [ ] `/raid quick title:Тест time:<через 30 минут> ping:@Рейдер` → в канале реги упоминание роли; записавшимся приходит **одно** напоминание, а не два.
- [ ] Записаться с обоих аккаунтов. Вторым отписаться (рейд меньше чем через 3 часа) → в канале оповещений «поздняя отписка» с пингом офицеров.
- [ ] За 15 минут до начала — «Сбор!» в канале реги с упоминанием записавшихся.
- [ ] Через 15 минут после начала — отчёт о посещаемости в канале оповещений: кто в голосовом, кто не пришёл, кто «под вопросом», кто пришёл без записи.
- [ ] «Расписание рег» → у расписания выбрать «роль для пинга», затем `/raid open-now` → реги открылись с упоминанием роли.

### Кто кого пригласил

- [ ] Создать приглашение, зайти по нему вторым аккаунтом → в «лог-дискорда» в записи о входе видно, по чьему приглашению зашёл новичок.

## 3. Работало раньше — быстрая перепроверка

- [ ] `/ping` отвечает.
- [ ] Приветствие: в админке «Прислать пробное приветствие»; второй аккаунт заходит → приветствие, кнопка «Получить роль Гость» выдаёт роль.
- [ ] Реги: `/raid quick` → колонки по ролям, иконки спеков, номера записей; запись (класс → спек), «Под вопросом», отписка; `/raid cancel`.
- [ ] Реги по расписанию: `/raid open-now` → открылись в каналах из «Расписания рег».
- [ ] Напоминания в личку: рега на завтра — за сутки, рега через час с небольшим — за час.
- [ ] Опросы: `/poll create file:…` с [примером](../examples/poll-example.txt) → «Пройти опрос», несколько страниц; `/poll results` — итоги и таблица; `/poll close`.
- [ ] Фильтр мата (со второго аккаунта) → сообщение удалено, одна запись в «лог-модерация», без дубля в «лог-сообщения».
- [ ] Модерация: `/mute`, `/unmute`, `/clear`, `/kick`, `/ban`, `/unban` → записи в «лог-модерация»; ручной тайм-аут через Discord тоже попадает туда, с тем, кто его дал.
- [ ] Логи: изменить и удалить сообщение → «лог-сообщения»; зайти в голосовой → «лог-голос»; переименовать канал или создать роль → «лог-сервер» с тем, кто это сделал.
- [ ] Админка: вход через Discord; аккаунт без права «Управлять сервером» видит «Нет доступа»; любое сохранение пишется в «лог-сервер».

## Если что-то не так
