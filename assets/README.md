# Картинки бота

Положи сюда файл **`raid-banner.jpg`** (можно `.png` или `.webp`). Это фон-баннер, который бот покажет вверху каждой реги, например арт с Древом Тельдрассил.

- Лучше всего смотрится горизонтальная картинка примерно 1200×500.
- Размер файла — до 2–3 МБ: бот заново загружает баннер при каждом обновлении состава.
- Если файла нет, рега будет без картинки.
- Бот ищет файл при каждом обновлении, поэтому перезапускать его после добавления картинки не нужно.

## Значки ролей — папка `role-icons`

Круглые значки танка (`tank.png`), лекаря (`healer.png`), бойца (`dps.png`, у ближнего боя) и ведущего (`leader.png`) — из окна поиска группы в игре. Бот загружает их как свои эмодзи при запуске.

Чтобы поменять значок, положи сюда PNG **с новым именем**: квадрат 64–128 px, до 256 КБ. Потом поменяй имя файла в `src/raids/emojis.ts` (`UI_ICONS`) и перезапусти бота. Если оставить старое имя, бот новую картинку не возьмёт: эмодзи с таким именем у него уже есть.
