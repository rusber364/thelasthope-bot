## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Владелец хочет, чтобы при открытии реги в канале бот ещё и присылал её в личку: упоминание роли в канале легко пропустить. Рассылать тем, кого рега упоминает (роли «Упомянуть» шаблона), с кнопкой «Не присылать мне» — массовые ЛС без отписки рискуют жалобами на спам, и Discord может ограничить бота.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 В шаблоне сбора есть галочка «Разослать в личку при открытии» (по умолчанию выключена)
- [x] #2 При открытии реги по шаблону с галочкой — по расписанию или «Создать регу сейчас» — участникам с ролями из «Упомянуть» приходит сообщение со ссылкой на регу
- [x] #3 Рассылка идёт с паузой между сообщениями, не задерживает публикацию, итог (сколько отправлено, сколько с закрытой личкой) — в «Логе бота»
- [x] #4 Кнопка «Не присылать мне» отключает рассылку для человека на этом сервере, «Снова присылать» — возвращает
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
