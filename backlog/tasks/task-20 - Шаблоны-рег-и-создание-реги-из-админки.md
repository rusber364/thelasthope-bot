## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Raid-Helper Premium хранит профили форм для быстрого создания событий. Офицерам удобнее создавать типовые рейды в два клика.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 В админке можно сохранить шаблон: название, описание, размер, время, канал, роль для пинга
- [x] #2 Из шаблона создаётся рега на выбранную дату
- [x] #3 Шаблоны можно редактировать и удалять
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. botSettings.raidTemplates (название, описание, размер, время, канал, роль для пинга) + проверка в validateSettings.
2. Админка: страница «Шаблоны рег» — редактирование списка (строки, удаление галочкой, пустая строка для нового) и у каждого шаблона форма «Создать регу» (дата + время, по умолчанию из шаблона).
3. Создание: проверка даты/времени и прав бота в канале, publishRaid (автор — вошедший админ), запись в лог-сервер, ссылка на регу.
4. Тесты админки, руководство, чек-лист.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Шаблоны — в настройках (raidTemplates) с проверкой в validateSettings; стабильный id шаблона. Создание из админки проверяет дату/время в будущем, канал и права бота, публикует через publishRaid (автор — вошедший админ, пинг роли из шаблона), пишет в лог-сервер. Тест админки: сохранение, ошибка без канала, создание реги на завтра 21:00 с описанием/пингом, прошедшая дата, правка, удаление, 404 на удалённый шаблон. Всего 149/149, typecheck.
<!-- SECTION:NOTES:END -->
