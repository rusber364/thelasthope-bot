## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Фильтр мата настраивался только в коде (src/settings.ts) и всегда удалял сообщение и мутил за повторы. Владелец хочет управлять цензурой из админки: выключать её совсем, выбирать строгость (только мат или ещё и грубые слова) и реакцию на нарушение.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 В админке есть страница «Фильтр мата»: выключатель, «какие слова» (только мат / мат и грубые слова), «что делать» (только сообщить модераторам / удалить / удалить и мутить за повторы), число нарушений, окно и длительность мута, каналы-исключения и свои слова
- [x] #2 Изменения действуют без перезапуска бота
- [x] #3 На уровне «только мат» грубые слова вроде «сука», «мудак» не ловятся, мат и оскорбления-ругательства по национальности и ориентации — ловятся
- [x] #4 «Только сообщить» не удаляет сообщение и присылает карточку в канал инцидентов; выключенный фильтр ничего не делает
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Настройки фильтра переезжают из src/settings.ts в botSettings.profanity (умолчания = прежнее поведение). profanity.ts: корни делятся на мат (всегда, со слюрами) и грубые слова (уровень rude). events/profanityFilter.ts::checkProfanity читает настройки на каждом сообщении: enabled, исключения, level, action report|delete|mute. API: раздел PUT /api/settings/profanity. Админка: страница «Фильтр мата» в группе «Сервер».
<!-- SECTION:PLAN:END -->
