## Description

Carl-bot Premium (Drama Watcher) присылает инциденты в канал модераторов с кнопками действий — не нужно искать по логам.
<!-- SECTION:DESCRIPTION:END -->

- [x] #2 Кнопки «Мут», «Бан», «Пропустить» выполняют действие с проверкой прав нажавшего
- [x] #3 Действия попадают в лог-модерация

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Настройка alerts.incidentChannelId (выбор на странице «Оповещения»; пусто — инциденты выключены).
2. logs/incidents.ts: карточка инцидента (кто, где, что, возраст аккаунта) с кнопками «Мут 1 ч», «Бан», «Пропустить». Источники: удаление мата (из фильтра), вход аккаунта младше 3 дней, массовые упоминания (5+ людей/ролей или @everyone без права).
3. Кнопки incident:*: проверка прав нажавшего (мут — «Модерировать участников», бан — «Банить», пропуск — модератор) и иерархии ролей; бан — с подтверждением; после решения кнопки убираются, в карточке «Решение: … — кто»; всё пишется в лог-модерация.
4. Тесты (карточка, проверки прав, мут/бан/пропуск, мат → инцидент, детекторы), руководство, чек-лист.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Канал инцидентов — отдельная настройка на странице «Оповещения» (без пинга роли, чтобы не шуметь). Источники: удаление мата (из фильтра), вход аккаунта младше 3 дней, 5+ упоминаний людей/ролей или @everyone без права. Бан — с подтверждением (ephemeral), удаляет сообщения за сутки; работает и для ушедших. Иерархия: наказать можно только того, чья роль ниже (владелец — без ограничений). Тесты src/logs/incidents.test.ts (6, в т.ч. мат → карточка через настоящий фильтр); всего 165/165, typecheck.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Инциденты модерации: удаление мата, вход совсем нового аккаунта и массовые упоминания публикуются карточкой в канал инцидентов (выбирается на странице «Оповещения»).
