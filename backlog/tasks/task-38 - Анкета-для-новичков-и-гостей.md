## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Опрос из админки, отмеченный как анкета новичков: кнопка «Пройти анкету» в приветствии, предложение тем, кто уже на сервере (публикация опроса с упоминанием роли), после заполнения — выдать/снять роль и карточка офицерам с ответами. Текст анкеты меняется через копию опроса.
