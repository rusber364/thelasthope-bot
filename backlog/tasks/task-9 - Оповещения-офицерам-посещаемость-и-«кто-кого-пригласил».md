## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Офицерам нужно вовремя узнавать о поздних отписках и неявках на рейд, а при входе новичка видеть, по чьему приглашению он пришёл.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Поздняя отписка или «под вопросом» меньше чем за N часов — оповещение с пингом офицеров
- [ ] #2 За N минут до рейда «Сбор!» в канале реги с упоминанием записавшихся
- [ ] #3 Через N минут после начала — отчёт о посещаемости по голосовому каналу
- [ ] #4 При открытии реги упоминается роль (расписание или /raid create ping)
- [ ] #5 В лог-дискорда при входе видно приглашение и его автора
- [ ] #6 Всё настраивается на странице «Оповещения» в админке
<!-- AC:END -->
