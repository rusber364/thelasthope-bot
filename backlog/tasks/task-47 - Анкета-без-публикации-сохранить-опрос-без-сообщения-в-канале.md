## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Анкету новичков хотят подготовить заранее и предлагать только из приветствия и в личке. Сейчас опрос в админке нельзя сохранить, не опубликовав сообщение в канал, а привязать к приветствию можно только открытый опрос — приходилось публиковать в скрытый служебный канал.
<!-- SECTION:DESCRIPTION:END -->

<!-- AC:BEGIN -->
- [x] #1 В редакторе опроса есть «Сохранить без публикации»: опрос сохраняется без канала и без сообщения в Discord
- [x] #2 Такой опрос можно сделать анкетой новичков, и он проходится из приветствия и из лички как обычный
- [x] #3 Список опросов, страница результатов, закрытие и CSV работают с опросом без канала (вместо канала — «без публикации»)
- [x] #4 Картинку-файл к опросу без публикации прикрепить нельзя — понятная ошибка
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Канал в базе остаётся NOT NULL — пустая строка = без публикации, в StoredPoll channelId: string | null. POST /api/polls с publish=0: без канала, роли и картинки-файла. closeAndRedraw, channelName, messageUrl, лог — без канала. В редакторе — вторая кнопка с подтверждением; после сохранения — страница опроса с кнопкой «Сделать анкетой новичков». Тесты store/service/api, документация.
