## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Raid-Helper Premium даёт игрокам ставить свои напоминания. Не всем подходят фиксированные «за сутки и за час».
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 На реге кнопка «Напомнить» с выбором времени (например, 10/30/60/120 минут)
- [x] #2 ЛС приходит в выбранное время и переживает перезапуск бота
- [x] #3 Напоминание можно отменить
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Таблица raid_personal_reminders (рега, человек, минуты, отправлено) и функции в store; перенос рейда сбрасывает отметку.
2. Кнопка «Напомнить» на реге → меню 10/30/60/120 минут и «Не напоминать» (видно только нажавшему).
3. Рассылка из планировщика каждые 30 секунд; сначала отметка, потом ЛС.
4. Тесты, руководство, чек-лист.
<!-- SECTION:PLAN:END -->
