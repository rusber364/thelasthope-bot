## Description

Carl-bot Premium периодически чистит каналы (например, флуд или ЛФГ).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 В выбранных каналах сообщения старше N часов удаляются по расписанию
- [x] #2 Учтено ограничение Discord на массовое удаление старше 14 дней
- [x] #3 Каналы и сроки настраиваются в админке
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. botSettings.autoClean: каналы {channelId, hours, keepBot} + проверка (1–720 ч, без повторов, до 20 каналов).
2. lib/autoClean.ts: раз в 10 минут и при запуске — сообщения старше N часов (поиск начиная с момента отсечки), без закреплённых и (по галочке) сообщений бота; моложе 14 дней — bulkDelete пачками по 100, старше — по одному, не больше 25 за проход (ограничение Discord).
3. Лог: сырые записи об удалении пропускаются (markDeletedByBot, в т.ч. для массового удаления), вместо них одна сводка «Автоочистка канала» в лог-сообщения.
4. Админка: страница «Автоочистка» (строки, удаление галочкой, пустая для нового), после сохранения — очистка сразу.
5. Тесты, руководство, чек-лист.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Чтение истории начинается с момента отсечки (snowflake), до 1000 сообщений за проход. Закреплённые не удаляются никогда, сообщения бота — по галочке (по умолчанию не трогать: реги, опросы, закрепы). Сырые записи об удалении подавляются (в т.ч. MessageBulkDelete, если вся пачка помечена), вместо них одна сводка. После сохранения в админке — проход сразу. Тесты src/lib/autoClean.test.ts (3) + тест админки; всего 156/156, typecheck.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Автоочистка каналов: в каналах из админки (страница «Автоочистка», срок 1–720 ч) бот раз в 10 минут и сразу после сохранения удаляет сообщения старше срока, не трогая закреплённые и (по галочке) свои. Учтено ограничение Discord: моложе 14 дней — пачками по 100, старше — по одному, не больше 25 за проход. В лог-сообщения — одна сводка.
