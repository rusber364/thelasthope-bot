## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Carl-bot Premium создаёт каналы, которые сами удаляются, — под разовые события и групповые активности.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Команда создаёт текстовый или голосовой канал со сроком жизни
- [x] #2 Канал удаляется по истечении срока, в том числе после перезапуска бота
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Команда /tempchannel name [type: текстовый|голосовой] hours [category]: создаёт канал (по умолчанию в категории текущего), пишет в нём, когда он удалится. Право команды — «Управлять каналами»; у бота — то же право (добавить в ссылку-приглашение).
2. Таблица temp_channels (канал, сервер, когда удалить, кто создал); lib/tempChannels.ts — проверка при запуске и раз в минуту: истёк — удалить канал; голосовой с людьми — подождать, пока опустеет; канал уже удалён руками — забыть.
3. Тесты команды и удаления, руководство, чек-лист, pnpm deploy — пользователю.
<!-- SECTION:PLAN:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Новая команда /tempchannel создаёт текстовый или голосовой канал со сроком жизни (1–720 ч); канал удаляется сам по сроку, в том числе после перезапуска (срок в базе), голосовой — когда опустеет. Проверено tempChannels.test.ts (нет права, создание в категории, удаление только по базе, голосовой с людьми, удалённый руками) и полным прогоном 159/159; нужны pnpm deploy и право «Управлять каналами» у бота.
