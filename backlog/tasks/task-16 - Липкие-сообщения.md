## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Carl-bot Premium держит сообщение последним в канале — для правил рег или важных объявлений.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Липкое сообщение заново публикуется внизу канала после новых сообщений (не чаще раза в N секунд)
- [x] #2 Тексты и каналы настраиваются в админке
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Настройка sticky {intervalSeconds 5–600, items: [{channelId, text}]} с проверкой; таблица sticky_messages (канал → id последней копии)
2. src/lib/sticky.ts: чистая nextRepostDelay (не чаще раза в N секунд, пачка сообщений — одна перестановка), обработчик MessageCreate с таймером на канал, перепубликация (удалить старую копию, отправить новую, запомнить id), refreshStickies для запуска и сохранения в админке
3. Админка: страница «Липкие сообщения» (интервал, строки канал+текст, пустая строка для новой, удаление галочкой)
4. Тесты: задержка, перепубликация с подменой таймеров, админка; документация
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Реализовано: настройка sticky {intervalSeconds 5–600, по умолчанию 15; items канал+текст} с проверкой (один закреп на канал), таблица sticky_messages (id последней копии), src/lib/sticky.ts (чистая nextRepostDelay: пауза тишины 3 с и не чаще интервала; таймер на канал — пачка сообщений даёт одну перестановку; своя копия распознаётся по подписи и не считается; refreshStickies при запуске и после сохранения — переставляет, если закреп не последний, и удаляет копии из убранных каналов), страница «Липкие сообщения» в админке. Проверено тестами: sticky.test.ts (задержки, перестановка с подменой таймеров: 5 сообщений → 1 перестановка, своя копия игнорируется, второй раз не раньше 15 с, прошлая копия удалена; сверка при запуске), тест админки (сохранение, пустой текст и два закрепа в одном канале — ошибки). В живом Discord не проверялось.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Липкие сообщения: бот держит заданный текст последним в канале — после новых сообщений удаляет прошлую копию и публикует заново, не чаще раза в N секунд и одной перестановкой на пачку. Тексты, каналы и интервал настраиваются на отдельной странице админки; id копий хранятся в базе (переживают перезапуск). Проверено: 120 тестов, в т.ч. sticky.test.ts и тест админки.
