## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->

3. Страницы настроек: каналы и роли, логи, оповещения, приветствие, липкие, автоочистка.
4. Расписание и шаблоны рег, посещаемость, опросы (список, редактор, итоги).
5. Бот раздаёт admin-ui/dist, старые HTML-страницы удаляются, документация и VPS-инструкция (pnpm build).
