## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Офицерам нужно видеть не только общую статистику опроса, но и ответы каждого человека целиком — сейчас это есть только в таблице для Excel.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 На странице опроса в админке две вкладки: «Общая статистика» (как раньше) и «По участникам» с числом ответивших
- [x] #2 «По участникам»: каждый человек отдельно — имя, завершил или нет, когда отвечал и все его ответы по вопросам
- [x] #3 В анонимном опросе ответы по участникам не показываются
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. polls/service.ts: answersByUser — ответы, сгруппированные по людям (только отвеченные вопросы, варианты названиями, сначала прошедшие опрос, свежие сверху).
2. Админка: вкладки «Общая статистика» / «По участникам (N)» на странице опроса; раскрывающиеся карточки людей с ответами по страницам; в анонимном опросе — только пояснение.
3. Тесты, руководство, чек-лист.
