## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Новый src/sveta/manners.ts — манеры Светы, чистые функции + маленький таймер:

1. speechHabits(её реплики из окна) → междометия в начале и эмодзи, повторённые ≥2 раз (и начало последней реплики); строка в инструкции «не начинай с … и без …»; dropOpener убирает такое междометие из начала ответа.

2. Короткий режим: deps.random() < BRIEF_SHARE → строка «ответь одной фразой; про сборы и состав — полностью».

3. reactionFor(текст без её имени и упоминаний, стикеры): спасибо → ❤️, смех → 😂, ок/ага/+ → 👍, только эмодзи/стикер → 😊; для обращений к ней (не swear) — message.react, без модели и лимитов.

4. quietRequest(«утихни/отстань/…») → QuietTimer на 2 ч для человека: случайно не встревает, обращения — с строкой «просил отстать: коротко, без подколов»; короткая просьба — реакция 👌 вместо текста.

5. typingDelay(длина) минус время генерации → sendTyping + deps.pause (в тестах нет).

6. Тесты, docs, выкладка на dev и главный.
